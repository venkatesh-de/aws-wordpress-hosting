# AWS WordPress Hosting Project

## Objective
To design a WordPress hosting architecture using AWS services.

## Planned Architecture
1. Create a VPC.
2. Create public and private subnets.
3. Launch an EC2 instance for WordPress.
4. Configure Amazon RDS for MySQL in private subnets.
5. Configure security groups and routing.
6. Document the setup and test connectivity.

## Security
- Keep the database private.
- Allow database access only from the WordPress EC2 security group.
- Restrict administrative access to trusted IP addresses.
